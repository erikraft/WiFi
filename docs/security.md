# Segurança do protótipo

Esta entrega contém uma interface inicial e um deep link, não um protocolo de transferência. Não há autenticação de pares nem transporte seguro implementados; não use para dados privados.

Antes de ativar comunicação, implementar e testar identidade de pares, consentimento explícito, autenticação mútua, criptografia ponta a ponta, proteção contra replay, validação de payloads, limites de tamanho e tempo, cancelamento e logs sem conteúdo sensível. Estar na mesma rede Wi-Fi não é uma prova de confiança.
